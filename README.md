# Ксения Андреева — Карьерный консультант

Сайт-визитка карьерного консультанта Ксении Андреевой.

## О проекте

Одностраничный сайт на чистом HTML/CSS/JS. Помогает клиентам:
- разобраться в карьерной ситуации,
- определить сильные стороны и подходящие направления,
- сменить профессию или сферу,
- найти удалённую работу,
- выйти на новый уровень дохода,
- подготовиться к собеседованиям.

## Технологии

- **HTML5** — семантическая разметка, мета-теги, Schema.org (ProfessionalService), Open Graph.
- **CSS3** — фирменная палитра (изумрудный + оранжевый), эффект матового стекла (glassmorphism), анимации, адаптивная вёрстка.
- **JavaScript** — бургер-меню, модальное окно с формой заявки, scroll-анимации, работа с формами.
- **SVG** — анимированный фон (градиент + летящие листья + мерцающие светлячки).
